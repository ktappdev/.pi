# PiHack Environment

Offensive security testing and penetration operations team.

## Agents
- **Recon** - Network reconnaissance and OSINT
- **WebHound** - Web application security testing
- **Exploit** - Exploitation and payload delivery
- **Cracker** - Password attacks and credential testing
- **Packet** - Network traffic analysis and sniffing
- **Ghost** - Post-exploitation and persistence
- **Sysadmin** - Active Directory and system administration attacks

## Teams
- **full-ops** - All agents for comprehensive assessments
- **web-audit** - Web application focused (Recon + WebHound + Exploit)
- **network-pentest** - Network focused (Recon + Packet + Ghost + Cracker)
